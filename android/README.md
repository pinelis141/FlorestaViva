# Floresta Viva — Live Wallpaper Android

Este diretório contém o aplicativo Android nativo de wallpaper animado em pixel art, com água da cachoeira animada, vaga-lumes, névoa, folhagem, luz e sombra. 

O workflow GitHub Actions compila `assembleDebug` e publica o artefato `FlorestaViva-APK`, disponível na aba Actions do repositório.

Arquivo de instalação após compilação: `app-debug.apk`.

Para ativar: instale no Android, abra o aplicativo e escolha Aplicar wallpaper.
